El camino que sigue todo dato

Si el profesor señala cualquier dato de la pantalla, la respuesta casi siempre es este recorrido. Ningún componente llama directamente a una API: lo hace por medio de un hook o un contexto, que usa un servicio.

→
Hook o contextoGuarda cargando, datos y error

→
APIDummyJSON, tasas de cambio o Laravel

Cómo leer las referencias

Antojos.jsx:69 significa: archivo Antojos.jsx, línea 69. En VS Code, Ctrl + P, escribe Antojos.jsx:69 y Enter para llegar directo. Para buscar una palabra en todo el proyecto: Ctrl + Shift + F.

Las líneas son las del 8 de noviembre de 2026. Si después se edita un archivo, los números pueden moverse: busca el nombre de la función, que no cambia.

El hook que hace las consultas: hooks/useFetch.js:23

export function useFetch(cargar) {
  // ...estado de la consulta y de la respuesta...
  useEffect(() => {                      // línea 33: corre al montar el componente
    let vigente = true                    // evita guardar una respuesta vieja
    consulta.cargar()
      .then((datos) => vigente && setRespuesta({ consulta, datos, error: null }))
      .catch((error) => vigente && setRespuesta({ consulta, datos: null, error }))
    return () => { vigente = false }        // limpieza al desmontar
  }, [consulta])
}

// 3. services/fuentes/dummyjson.js:83, aquí sale la petición HTTP
const { data } = await api.get('/products', { params: { limit: 0, select: CAMPOS_LISTADO } })

// app/Http/Controllers/AbonosController.php:24
public function store(AbonoStoreRequest $request, Meta $meta)  // valida antes de entrar
{
